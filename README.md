# 텍스트로 보는 행정사 웹교재

행정학의 고전 텍스트(공자, 키케로, 벤담, 클라우제비츠, 윌슨, 굿나우, 테일러, 베버, 화이트, 해링, 귤릭, 머튼, 사이먼, 왈도, 린드블롬, 프레드릭슨, 쉬크, 드로어)를 강독하는 학부 교재. 13개 주차(중간·기말 제외) × 주당 2차시 = 총 26개 장. 형식은 「AI 기반 공공데이터 분석」 웹교재를 계승한다.

## 문서

- [목차.md](목차.md): 26개 장의 절 단위 목차 (확정)
- [집필지침.md](집필지침.md): 원전 인용 원칙, 번역투 재서술 규칙, 장 구조, 원전 읽기 박스 등

## 웹교재 (HTML)

Kwangwoon University 강의 교재 웹사이트로 빌드되어 있으며, GitHub Pages로 게시된다: https://hoor0015.github.io/admin-history-textbook/ (main에 푸시하면 자동 재배포). 본문(md)을 고친 뒤 `code/build_html.py`를 실행하면 다시 빌드된다.

## 원자료와 집필 방식

- 원자료: `_sources/교재원문.md`(hwp 교재 추출본, 원전 단위 분할본은 `_sources/교재분할/`), `_sources/ppt/`(강의 슬라이드 23종 텍스트).
- 각 장의 중심은 hwp 교재의 원전 번역 발췌(원전 읽기 박스)이며, PPT는 해설 구조 참고용.
- 교재 번역문의 번역투는 의미를 보존하며 자연스러운 한국어로 재서술했고, 모호한 대목은 공개 영어 원전(구텐베르크, econlib, 학술지 원문 등)과 대조했다.
- 원자료의 사실 오류를 웹 검증으로 교정한 사례: 키케로 피살 연도(BC 44 → BC 43), 블룬칠리 표기, 이튼의 위원장 시기, 드로어 생몰(1928-2026) 등.
